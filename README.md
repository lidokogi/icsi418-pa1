My Task List

Name: Lucille Idokogi 

WHAT IT DOES
A simple to-do list app where you can add tasks, pick a priority (Low, Medium, High), mark them as completed, and delete them. Everything is stored in memory, so the list resets if you refresh the page.

HOW TO RUN IT
Clone the repo
Open index.html in your browser (or use the Live Server extension in VS Code)
Type a task, pick a priority, and click "Add Task"
Known issues / incomplete features
Tasks don't save after refreshing the page
No way to edit a task once it's added, only complete or delete it
